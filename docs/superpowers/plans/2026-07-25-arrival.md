# The Arrival Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the post-join moment feel like arriving — restyle the welcome banner as "Welcome in, {name}" + a MEMBER stamp + two verbs — and tell the neighbor who vouched that someone joined ("{name} joined — say hi").

**Architecture:** Two units. (A) A host notification: a new `MEMBER_JOINED` notification type, and a best-effort `notifyMemberJoined` helper fired from inside the two attributed-join markers in `src/lib/invite.ts` (`acceptInvitation` → the invite's sender; `attributeJoinCode` → the library owner). (B) A new `ArrivalWelcome` component replacing the plain success Alert in `CollectionDetailClient`.

**Tech Stack:** Next.js App Router, Prisma (committed migrations), MUI, Vitest + @testing-library/react.

**Spec:** `docs/superpowers/specs/2026-07-25-arrival-design.md`. **Branch:** `feat/arrival` (already created off `main`, spec committed). Husky prints a deprecation warning on commit — ignore it. Commit messages get a one-line `Why:` trailer plus the `Co-Authored-By:` line.

**Grounding facts (verified):**

- The two markers today: `acceptInvitation(token, collectionId, userId)` does one `db.invitation.updateMany`; `attributeJoinCode(userId, collectionId, codeId)` does `db.collectionMember.updateMany` + `recordJoinCodeUse`. Both are only ever called on a real attributed join (callers guard on `created || reactivated`).
- `createNotification` (in `src/lib/notification-service.ts`) takes `{ userId, type, title, message, actionUrl?, relatedItemId?, relatedRequestId?, metadata? }`; `actionUrl` is the link. It only dedupes when a `relatedItemId`/`relatedRequestId` discriminator is present (none here — one notification per join is fine).
- The welcome banner lives at `CollectionDetailClient.tsx` ~L759-794 (`showWelcomeBanner`, `currentUserName`). The add-item verb already exists as `handleAddNewItem` (~L471, pushes `/add-item?library=<id>`).

```ts
/**
 * Tell the neighbor who brought someone in that they arrived. Best-effort: the
 * join has already happened by the time this runs, so a notification failure
 * must never surface. Never notifies the joiner about themselves.
 */
export async function notifyMemberJoined(opts: {
  collectionId: string;
  newMemberId: string;
  recipientId: string | null | undefined;
}): Promise<void> {
  const { collectionId, newMemberId, recipientId } = opts;
  if (!recipientId || recipientId === newMemberId) return;
  try {
    const [member, collection] = await Promise.all([
      db.user.findUnique({
        where: { id: newMemberId },
        select: { name: true },
      }),
      db.collection.findUnique({
        where: { id: collectionId },
        select: { name: true },
      }),
    ]);
    const firstName = member?.name?.trim().split(/\s+/)[0] || 'A neighbor';
    const libraryName = collection?.name || 'your library';
    await createNotification({
      userId: recipientId,
      type: 'MEMBER_JOINED',
      title: 'A neighbor joined',
      message: `${firstName} joined ${libraryName} — say hi`,
      actionUrl: `/library/${collectionId}`,
    });
  } catch {
    // best-effort: never fail a join because a notification could not be sent
  }
}
```

```ts
export async function acceptInvitation(
  token: string,
  collectionId: string,
  userId: string
): Promise<void> {
  await db.invitation.updateMany({
    where: { token, libraryId: collectionId },
    data: { status: 'ACCEPTED', acceptedAt: new Date(), receiverId: userId },
  });

  // Tell the sender their invitee arrived. Wrapped so the lookup can never
  // fail the accept.
  try {
    const invitation = await db.invitation.findFirst({
      where: { token, libraryId: collectionId },
      select: { senderId: true },
    });
    await notifyMemberJoined({
      collectionId,
      newMemberId: userId,
      recipientId: invitation?.senderId,
    });
  } catch {
    // best-effort
  }
}
```

```ts
  codeId: string
): Promise<void> {
  await db.collectionMember.updateMany({
    where: { userId, collectionId },
    data: { joinedViaCodeId: codeId },
  });
  await recordJoinCodeUse(codeId);
```

```ts
      where: { id: collectionId },
      select: { ownerId: true },
    });
    await notifyMemberJoined({
      collectionId,
      newMemberId: userId,
      recipientId: collection?.ownerId,
    });
  } catch {
    // best-effort
  }
}
```
